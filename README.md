# Experimental Data

This folder contains the experimental data reported in the preprint: “Rolling stability in slender swimmers at water surface: resonance, energetic trade-off and template.”

The data are provided as CSV files following the naming convention:

`Fig_{number}{letter}.csv`, for example: "Fig_4C.csv"
 

Each CSV file contains the numerical data extracted from the corresponding figure of the preprint.

## Data reader

A MATLAB script is provided to read and plot the CSV data:

`CSV_DATA_READER.m`

 
To use it:

1. Open MATLAB.
2. Run `CSV_DATA_READER.m`.
3. Select the CSV file you wish to read.
4. The script will load the data and display the corresponding data series.

The data are provided in CSV format to facilitate reuse, analysis, and reproducibility.
